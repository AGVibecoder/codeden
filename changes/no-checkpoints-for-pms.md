- **A project manager is free again as soon as its turn ends.** After every turn, CodeDen saved a checkpoint of the session's folder, also for the orchestrator and project managers, whose folder is the whole project. In a big project on a slow disk that took minutes, the project manager counted as busy meanwhile, and your next message waited in the queue. The orchestrator and project managers are read-only and never change files, so they no longer get checkpoints. Agent sessions still do.
