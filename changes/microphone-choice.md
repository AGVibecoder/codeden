- **Choose your microphone.** Settings → Voice → Dictation → **Microphone** picks the microphone for dictation, calls, the wake word and the Whisper test, instead of always the system default. If it's unplugged, the system default is used until it's back. **Check** shows a live level bar so you can see that CodeDen hears you. Local Whisper also no longer types "Thank you" or "Thanks" when it hears only silence.
