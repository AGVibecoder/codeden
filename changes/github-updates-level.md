- **Choose which GitHub activity reaches the project manager.** Each GitHub project has a GitHub updates level: Off (nothing reaches the PM; it all stays on the GitHub tab), Digest (no wake-ups, just a short summary in the PM's next turn), Important, the default (only failed checks, change requests, merges and merge conflicts on PRs CodeDen opened) or All (everything, waking the PM at most once every 15 minutes). New issues and pull requests from other people no longer wake the PM unless the level is All. Change it from the "GitHub: Important" chip in the PM chat header, with "Mute these" on a batch of GitHub updates in the chat, or in the project's Settings tab.
