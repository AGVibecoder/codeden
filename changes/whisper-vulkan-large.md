- **Local Whisper runs on your graphics card, with Large v3 Turbo.** On Windows with an NVIDIA or AMD Radeon card, CodeDen downloads Whisper's Vulkan build and runs it on the card (falling back to the processor if that build doesn't load); Settings says which. The only model is now Large v3 Turbo (547 MB), which recognises Dutch and other languages far better than the smaller models it replaces. Very short phrases are padded to a second so Whisper catches them.
