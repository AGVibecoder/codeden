- **Publish a local project to GitHub.** A local project's home page has **Publish to GitHub**: pick the owner, the name and Private or Public, and CodeDen creates the repository and pushes. It first makes the folder a git repository if needed, adds a `.gitignore` for Unreal, Unity, Node.js or Python projects (an Unreal project leaves out Binaries, Intermediate, Saved and DerivedDataCache), stores game assets with Git LFS, and makes a first commit. The dialog shows all of it, with the number of files and their size, before anything changes. Afterwards the project is a GitHub project, so issues, pull requests and the software factory work for it.
