- **Voice calls: no visible note, no length limit, never blocked.** The instruction a call adds to your messages is now hidden from the chat, and it no longer limits answers to one to three sentences: the orchestrator or project manager answers as fully as needed, describing lists and code in spoken words. A call that got stuck no longer blocks a new one: the phone button hangs it up, and starting a call ends any other.
